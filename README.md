# 🎮 Hangman Game (Java)

## 📌 Overview
A simple console-based Hangman game built in Java where the player guesses a hidden word letter by letter within limited attempts.

## ✨ Features
- Random word selection
- Letter-by-letter guessing
- 6 wrong attempts allowed
- Warning system for invalid/repeated input
- ASCII Hangman visuals
- Colored console output

## 🧠 How to Play
- Guess one letter at a time
- Correct letters are revealed
- Wrong guesses reduce attempts
- Win by guessing the full word before attempts run out

## 🛠 Technologies Used
- Java
- Scanner Class
- Random Class
- Array & String handling

## 🚀 Learning Outcome
- Strengthens logic building
- Improves string manipulation skills
- Practice of loops, conditions, and game design
